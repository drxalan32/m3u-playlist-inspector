# Security Policy

## Supported versions

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please do not publish sensitive security reports, credentials, private playlist URLs, or customer data in public issues. Use GitHub's private vulnerability reporting feature if it is enabled for this repository.

## Data handling

M3U Playlist Inspector reads local text files and does not make network requests. Treat playlist files as sensitive: they may contain private URLs, tokens, or account information. Do not share them publicly.
