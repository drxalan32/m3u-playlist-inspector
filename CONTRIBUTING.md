# Contributing

Thanks for considering a contribution to M3U Playlist Inspector.

## Before opening an issue

- Search existing issues to avoid duplicates.
- Describe the expected behavior and what happened instead.
- Include your Python version and operating system.
- Use synthetic examples such as `https://example.com/sample.m3u8`.

## Privacy and safety

Never include real subscription links, private playlist files, usernames, passwords, tokens, customer data, or copyrighted media in issues, pull requests, screenshots, or test fixtures.

## Development

The project uses only the Python standard library.

```bash
python3 -m unittest discover -s tests -v
```

Keep changes focused, add tests for bug fixes, and update the README when command behavior changes.
