How to Convert M3U to CSV (and Open It in Excel or Google Sheets)

A long playlist is hard to clean up in a text editor. In a spreadsheet you can sort by group, search names, fix many entries at once and then turn the result back into a playlist. The M3U playlist converter does the conversion in your browser, without uploading the file.

Step 1: Convert the playlist to CSV

  1. Open the converter and choose your .m3u or .m3u8 file.
  2. Select CSV as the output and check the preview.
  3. Download the .csv file.

What the CSV contains

One header row and one row per entry, with these columns:

name,url,duration,tvg-id,tvg-name,tvg-logo,group-title

For this playlist:

#EXTM3U x-tvg-url="https://guide.example/epg.xml"
#EXTINF:-1 tvg-id="a" tvg-logo="https://e.test/a.png" group-title="News, Sports",Channel A
#EXTVLCOPT:http-user-agent=Foo
https://example.com/a.m3u8
#EXTINF:120,"Quoted" Name
https://example.com/b.mp4

the CSV is:

name,url,duration,tvg-id,tvg-name,tvg-logo,group-title
Channel A,https://example.com/a.m3u8,-1,a,,https://e.test/a.png,"News, Sports"
"""Quoted"" Name",https://example.com/b.mp4,120,,,,

Values that contain commas or quotation marks are wrapped in quotes, so News, Sports stays in one cell. A spreadsheet program reads this correctly.

Step 2: Open it in a spreadsheet

Google Sheets: choose File, then Import, upload the CSV and keep the separator type on comma. Excel: use Data, then From Text/CSV, and set the file origin to UTF-8 if names with accents or non-Latin letters look garbled. Double-clicking a CSV may use a different encoding on some systems.

Step 3: Edit, then convert back

Edit names, groups or logo addresses, but keep the header row and the column names. Save as CSV (not .xlsx), then load that file into the converter and choose M3U as the output. Rows without a url cannot become playlist entries.

What is not carried over

  • The #EXTM3U header attributes such as x-tvg-url.
  • Extra tags such as #EXTVLCOPT.

Only the seven columns above round-trip. If your playlist depends on other tags or on the guide link, add them back to the finished file in a text editor.

A note on formulas

A cell that starts with =, +, - or @ can be run as a formula by a spreadsheet. To prevent that, the converter puts an apostrophe in front of such text. Plain numbers such as the duration -1 are left alone.

Playlists from streaming services often include a username or token in each address, and the CSV will contain them too. Keep the file private and do not share it.

Frequently asked questions

Can I convert M3U to JSON instead?

Yes. The same converter exports JSON and can convert supported JSON back to M3U.

Is the file uploaded?

No. Conversion runs in your browser. See the privacy page.
