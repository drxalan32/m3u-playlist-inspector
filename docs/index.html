What it checks

01

Header and entries

Check the extended M3U header and find entries that are missing media URLs or metadata.

02

EXTINF syntax

Get started

Run your first playlist check.

Download the source, open a terminal in the project folder and run the inspector with a local playlist path.

TerminalPython 3.9+
# Clone the repository
git clone https://github.com/drxalan32/m3u-playlist-inspector.git
cd m3u-playlist-inspector

# Inspect a local playlist
python3 m3u_inspector.py path/to/playlist.m3u

# Export JSON and CSV reports
python3 m3u_inspector.py path/to/playlist.m3u --json report.json --csv report.csv

# Display parsed entries
python3 m3u_inspector.py path/to/playlist.m3u --show-entries

Know the format

What is an M3U8 playlist?

M3U is a text-based playlist format. Extended M3U files commonly begin with #EXTM3U and use #EXTINF lines to describe media entries. M3U8 is commonly used for UTF-8 encoded playlist text.

FAQ

Frequently asked questions.

Does the inspector test whether a stream is online?

No. It checks local playlist structure only. It does not connect to media URLs, test playback or verify availability.

Are playlist contents uploaded anywhere?

No. The command-line tool reads the file locally and does not send playlist contents to an external service. Keep private URLs and credentials out of public bug reports.

Do I need to install Python packages?

No third-party packages are required. The project uses the Python standard library and requires Python 3.9 or newer.

Does a clean report prove that a playlist is safe or licensed?

No. A structural check does not verify ownership, licensing, security or whether media can be played. Only inspect playlists you own or are authorized to use.
