How to merge M3U files online

  1. Select two or more local .m3u or .m3u8 files.
  2. Choose whether to remove exact duplicate stream URLs.
  3. Select Merge playlists to combine entries under one #EXTM3U header.
  4. Review the preview, then download the merged M3U file.

When duplicate URLs are found, the first entry is kept. Its original EXTINF metadata remains attached to that URL. Other entries and their metadata are preserved in their original order.

How the M3U playlist merger handles your files

Each selected file is read as text in your browser. The merger collects playlist entries, writes one #EXTM3U header and places the entries into a single output. It does not combine, convert or re-encode the underlying video or audio streams.

Exact URL matching and duplicate removal

When the duplicate-removal option is enabled, the tool compares the complete URL strings. It keeps the first occurrence and skips later entries with the same exact URL. Two different URLs with the same channel name remain separate entries. This is text-based deduplication, not a check for equivalent streams.

Preserving entry metadata

Keep the metadata option enabled to retain the comment and metadata lines associated with each entry, including its #EXTINF line. If you turn it off, those lines are omitted from the merged output; use that setting only if you intentionally want a URL-only list.

Before you merge

  • Keep a backup of the original playlist files.
  • Use files you own or are authorised to manage.
  • Review the preview, especially if the source playlists use custom tags.
  • Remember that a successful merge does not confirm stream availability or playback.

Frequently asked questions

Can I merge M3U and M3U8 files together?

Yes. The merger reads both as UTF-8 playlist text and combines their entries into one downloadable M3U playlist. It does not transcode media streams.

Does this upload my playlist to a server?

No. File reading, merging and export happen locally in your browser. The page does not send playlist contents to a processing server.

Will merging make every channel work?

No. Merging only combines playlist entries. It does not test stream availability, playback, account access, content rights or provider reliability.

How are duplicate channels identified?

When duplicate removal is enabled, entries are compared by their exact stream URL. Different URLs with the same channel name are kept because they may represent different streams.
