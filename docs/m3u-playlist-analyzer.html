What this analysis checks

  • Entries and unique URLs: counts stream URL lines and distinct exact URL values.
  • Duplicate URLs: identifies repeated exact URL strings, not channels with similar names.
  • Metadata: checks whether each URL has an associated EXTINF line and a non-empty display name.
  • Categories: groups entries by the group-title attribute when present.
  • Protocols: groups URLs by their detected scheme, such as HTTP, HTTPS or RTSP.

This is a structural report only. It does not connect to stream URLs or determine whether a stream works, is safe, authorised or available.

Frequently asked questions

Does the analyzer upload my playlist?

No. The selected file is read and analysed locally in your browser. Playlist contents are not sent to a processing server.

Does it check if channels are online?

No. It analyses text structure and URL patterns only. It does not request stream URLs or test playback.

How are duplicate URLs counted?

URLs are compared as exact strings. Two different URLs with the same channel name are counted separately.

What does missing metadata mean?

An entry is marked as missing EXTINF when no preceding EXTINF line is attached to it. A missing name means the EXTINF line has no display name after its comma, or the entry has no EXTINF line.
