M3U vs M3U8: What's the Difference?

M3U and M3U8 are filename extensions commonly used for text-based media playlists. They can describe media locations and, in extended playlists, include metadata such as entry names and durations. The main distinction commonly associated with the extensions is text encoding: M3U8 indicates UTF-8 encoded playlist text.

The extension alone does not tell you every tag a file contains, whether a media location works, or whether the file follows every detail of a particular streaming specification.

What does an extended M3U playlist look like?

A simple extended playlist can contain a header, an information line and a media location:

#EXTM3U
#EXTINF:-1,Example item
https://example.com/media/example.m3u8
  • #EXTM3U marks an extended M3U playlist.
  • #EXTINF describes the next media entry.
  • The text after the comma is commonly used as the display name.
  • The following line contains the media location.

Can you rename an M3U file to M3U8?

Changing a filename extension does not convert the text encoding. If a file contains characters that are not represented correctly in its current encoding, renaming it will not fix those characters. Use a text editor or a conversion process that explicitly reads the source encoding and writes UTF-8, then verify the result with the software that will consume the playlist.

Does M3U8 always mean HLS?

No. The .m3u8 extension is associated with UTF-8 playlist text and is also widely used for HTTP Live Streaming (HLS) playlists. But an M3U8 file is not automatically a valid HLS media or master playlist. HLS uses additional tags and rules defined by its specification.

How can you check an M3U or M3U8 file?

Start by checking that the file is readable text and that its playlist records are structurally consistent. Look for a valid extended header when expected, complete #EXTINF records, media locations and unexpected duplicate entries.

M3U Playlist Inspector can check supported local playlist structure without uploading the file or connecting to media URLs. See the step-by-step M3U validation guide for installation and commands.

Important limitations

A format or structure check cannot prove that a stream is online, playable, secure or licensed. This project does not perform network checks or verify content rights. Only inspect playlist files and media locations you own or are authorized to use.

Frequently asked questions

Which extension should I use?

Use the extension expected by the application or workflow that will read the file. Make sure the actual text encoding matches the format convention; do not rely on renaming alone.

Can an M3U file contain UTF-8 text?

Yes. Real-world M3U files can use different encodings. The .m3u8 extension conventionally signals UTF-8, but software compatibility should be checked with the intended reader.

Can a playlist validator check playback?

Not unless it deliberately connects to and tests media resources. M3U Playlist Inspector is local-only and checks playlist structure; it does not test playback or availability.
