#EXTINF Explained: Duration, Attributes and Name

#EXTINF is the line that describes the media entry on the line after it. A player reads it to get the entry's length and display name, and often extra attributes such as a logo or group. Most playlist problems that look mysterious come from one malformed #EXTINF line.

The anatomy of a line

#EXTINF:-1 tvg-id="news.one" group-title="News",Example News
https://example.com/stream/news.m3u8
PartExampleMeaning
Tag#EXTINF:Starts the entry description
Duration-1Length in seconds; -1 means unknown, which is normal for live streams
Attributes (optional)tvg-id="news.one" group-title="News"key="value" pairs read by many players
Comma,Separates the description from the name
NameExample NewsDisplay name shown in the player

The very next line must be the media address. For what the attributes mean, see M3U attributes explained.

Which comma separates the name?

The name starts after the first comma that is outside double quotes. A comma inside an attribute value belongs to the value:

#EXTINF:-1 group-title="News, Sports",BBC One

Here the group is News, Sports and the name is BBC One. Commas after the separator stay part of the name, so Hello, World is a valid name.

Broken examples and what goes wrong

No comma

#EXTINF:-1 BBC One

Without the comma there is no name. Our checker reports an invalid #EXTINF line, and players may show a blank name or skip the entry.

Duration that is not a number

#EXTINF:live,BBC One

The duration must be a number such as -1, 0, 215 or 12.5. Words like live are reported as an invalid #EXTINF.

Empty name

#EXTINF:-1,

The line is well formed but the name is empty, so the checker reports an empty name. How a player displays such an entry depends on the player.

No address on the next line

#EXTINF:-1,BBC One

If the next line is another #EXTINF or the file ends, the entry has no media address and is reported as missing its URL.

Duration in practice

For a music file the duration is its length in seconds, for example #EXTINF:215,Artist - Song. For live streams and most IPTV-style playlists it is -1. Some players ignore the number, but a non-numeric duration makes the line invalid for stricter readers.

Check your own file

Paste a playlist into the M3U playlist checker to see which #EXTINF lines are malformed and on which line number. It reads the file locally in your browser and does not open the streams.

Frequently asked questions

Is #EXTINF case sensitive?

The tag is normally written in capitals. Our checker accepts lowercase #extinf, but other software may not, so use capitals.

Do I need #EXTINF at all?

A plain list of addresses works in many players. Without #EXTINF there is no name, duration or attributes for the entry, and the checker notes a URL without #EXTINF.

Can the name contain special characters?

Yes. Save the file as UTF-8 so accents and non-Latin letters display correctly. See M3U vs M3U8.
