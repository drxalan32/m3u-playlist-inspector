M3U Playlist Inspector · Browser tools

IPTV M3U tools to check, create and manage playlists

Choose the right tool for the job. M3U Playlist Inspector brings together browser-based utilities for checking playlist structure, creating a playlist, editing entries, combining files, reviewing metadata and converting supported formats. Your selected files are processed locally in your browser unless a tool's own page clearly states otherwise.

Privacy and scope: These tools work with playlist text and file structure. They do not test whether media URLs are online, verify playback, assess provider reliability or determine content rights. Only use playlists and media URLs you own or are authorised to use.
