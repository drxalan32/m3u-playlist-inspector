M3U Attributes Explained: tvg-id, tvg-logo and group-title

Besides the standard #EXTINF duration and name, many playlists add key="value" attributes. They are not part of the basic M3U idea, but they are a widespread convention that IPTV and media players read to show logos, sort channels into groups and match channels to a program guide (EPG).

#EXTM3U x-tvg-url="https://example.com/guide.xml"
#EXTINF:-1 tvg-id="example.one" tvg-name="Example One" tvg-logo="https://example.com/logo.png" group-title="News",Example One
https://example.com/stream/one.m3u8

The common attributes

AttributeWhereWhat players typically use it for
x-tvg-url#EXTM3U lineAddress of the XMLTV guide file for the whole playlist
tvg-id#EXTINF lineMatches the entry to a channel ID in the guide
tvg-name#EXTINF lineAlternative name used for guide matching in some players
tvg-logo#EXTINF lineAddress of the channel logo image
group-title#EXTINF lineCategory or group the entry is listed under

Support differs between players. An attribute that works in one app may be ignored in another.

How the guide matching works

A guide file (XMLTV) lists programs per channel ID. For an entry to show its schedule, its tvg-id usually has to match a channel ID in that guide exactly, including letters and case. If the IDs do not match, the channel plays but shows no guide. A playlist checker cannot test this match; it only reads the playlist file.

Common mistakes

  • A comma inside a value. In group-title="News, Sports" the comma is part of the value. The name starts after the first comma outside the quotes.
  • Unclosed quotes. A missing closing quote can swallow the rest of the line, including the name.
  • Empty or duplicated tvg-id. Several entries sharing an ID, or an empty tvg-id="", can leave channels without a guide.
  • Logo addresses that no longer load. The file can be valid while the image address is dead.

Check and edit them

The playlist analyzer counts how many entries have tvg-id, logos and groups, which shows where metadata is missing. The M3U editor lets you change names, groups, logos and IDs, and the converter exports them to CSV for bulk edits in a spreadsheet. All of these run in your browser and do not upload the file.

Frequently asked questions

Is tvg-id required?

No. A playlist plays without it. It matters only if you want a program guide matched to the entry.

Where do I get a guide file?

From the provider of your playlist, or from a guide source you are allowed to use. This site does not supply guide data.
