How to Create an M3U Playlist File

You can create a basic M3U playlist file with any plain-text editor. An M3U file is text: it contains media locations and, in an extended playlist, optional information describing each item. This guide walks through a small demonstration file you can use to understand the format.

Use authorized media only. The sample below uses the reserved example.com domain as a placeholder. Replace it only with a media URL you own or are explicitly authorized to use. This tutorial does not provide channel lists or stream sources.

1. Open a plain-text editor

Use a plain-text editor such as Notepad on Windows, TextEdit in plain-text mode on macOS, or a code editor. Do not use a rich-text format such as .docx or formatted TextEdit documents.

2. Add the M3U header

For an extended M3U playlist, start the file with this header on the first line:

#EXTM3U

The header identifies the file as an extended M3U playlist. Keep it on its own line.

3. Add an entry and its media location

An extended entry commonly uses an #EXTINF line followed by the media location on the next line. Here is a safe, non-working placeholder example:

#EXTM3U
#EXTINF:-1 tvg-id="demo.example" tvg-name="Example Channel" group-title="Demo",Example Channel
https://example.com/stream.m3u8
  • #EXTINF introduces metadata for the next item.
  • -1 is commonly used for a live or unknown-length item.
  • tvg-id, tvg-name and group-title are optional metadata attributes used by some playlist applications; support varies.
  • The comma separates the metadata attributes from the display name.
  • The next line is the media location. The example URL is only a placeholder.

4. Add more entries

Repeat the same two-line pattern for each additional item: one #EXTINF line and then its corresponding authorized media location. Keep each location paired with the entry directly above it.

5. Save the file with the .m3u extension

Choose Save As, enter a name such as my-playlist.m3u, and select plain text if your editor asks for a file format. If you are saving UTF-8 text, use UTF-8 encoding where available. Check that your editor has not silently added an extra extension such as .txt.

6. Check the playlist structure

Before using the file, inspect it for common formatting mistakes. Try the M3U Playlist Inspector online checker: paste the example or select your local .m3u file. Processing takes place in your browser tab; the file is not uploaded.

The checker can report supported structural issues such as a missing header, incomplete entries, basic #EXTINF syntax problems and duplicate locations. You can also use the Python validation tutorial if you prefer a command-line workflow.

Common mistakes to avoid

  • Leaving out the #EXTM3U header in an extended playlist.
  • Forgetting the comma that separates #EXTINF metadata from the display name.
  • Adding a new #EXTINF before providing the previous entry's media location.
  • Saving the file as rich text or with an unintended .txt extension.
  • Sharing private media URLs, tokens or credentials in public examples or support requests.

What a successful check does not mean

A structurally clean M3U file is not proof that its media URLs are reachable, that playback will work, or that you have rights to distribute or access the content. M3U Playlist Inspector does not connect to media URLs, test playback, or verify licensing. Check only files and media sources you are authorized to use.

Frequently asked questions

Can I create an M3U file without special software?

Yes. A plain-text editor is enough to create a basic M3U playlist.

Should I save it as .m3u or .m3u8?

Use the extension expected by the application that will read the file. M3U8 is commonly associated with UTF-8 encoded playlist text, but the extension alone does not guarantee protocol compatibility.

Can I create an M3U playlist from media I find online?

Only use media locations you own or are authorized to access and include. A URL being publicly reachable does not automatically grant permission to use or redistribute its content.
