How to Open an M3U or M3U8 File

An M3U or M3U8 file is a plain-text list of media locations, not a video itself. Double-clicking it normally hands it to a media player, which then loads each address in the list. What you do depends on whether you want to play the playlist, read it or check it.

Open it to play the contents

Media players such as VLC, Kodi and many IPTV apps accept M3U and M3U8 files. In most of them you choose Open file or Add playlist and select the file, or paste a link if the playlist is hosted online. If the file does not open, the player may not support the format, or the addresses inside may be unavailable. The playlist file only lists locations; whether each one plays depends on the player and the source.

Open it as text to read or edit

Because the file is plain text, any text editor can open it: Notepad on Windows, TextEdit (in plain-text mode) on macOS, or an editor such as VS Code. This is the quickest way to see what is inside:

#EXTM3U
#EXTINF:-1,Example item
https://example.com/media/example.m3u8

Save M3U8 files as UTF-8 so that accented and non-Latin characters in names stay intact. Renaming a file from .m3u to .m3u8 does not change its encoding. See M3U vs M3U8 for details.

Open it in your browser to check its structure

If a playlist loads slowly, shows blank names or stops at a certain entry, check its structure before blaming the player. The M3U playlist checker reads the file in your browser and reports a missing #EXTM3U header, malformed #EXTINF lines, entries without a URL and duplicate URLs. The playlist analyzer gives counts of channels, groups and protocols. Both work locally: the file is not uploaded, and the tools do not open the streams or test playback.

Playlists from streaming services often contain a username, password or token in each address. Treat such a file like a password and do not share it or post screenshots of its URLs.

Frequently asked questions

Why does my computer ask which program to use?

Many systems have no default app for .m3u or .m3u8. Choose a media player, or open the file with a text editor if you only want to read it.

Can I open an M3U file on a phone?

Yes, with a player app that supports playlists, or by opening the file in a text editor app to read it. Browsers usually download the file rather than play it.

Is an M3U file the same as an MP3?

No. An M3U file is a text list that can point to MP3 or video files. It contains no audio or video of its own.
