M3U Playlist Converter: Convert M3U to CSV and JSON

Convert M3U and M3U8 playlists to CSV or JSON for editing and data workflows. You can also turn supported CSV or JSON playlist data back into an M3U file.

Local browser processing · No account · No playlist upload · No stream or URL checks

1. Select a file and conversion

M3U/M3U8 files can be exported as CSV or JSON. CSV/JSON files can be converted to M3U. Auto-detect exports M3U as JSON and imports CSV/JSON as M3U.

Choose a supported file to begin.

2. Preview and export

The converter preserves common channel fields where available: display name, stream URL, duration, tvg-id, tvg-name, tvg-logo and group-title. Unsupported custom tags may not be retained in CSV/JSON conversion.

How to convert an M3U playlist

  1. Select a local .m3u or .m3u8 file.
  2. Choose CSV or JSON as the output format. Auto-detect exports M3U/M3U8 input as JSON.
  3. Select Convert file and review the converted content in the preview.
  4. Download the converted file or copy its contents.

To convert structured data back to M3U, choose a CSV or JSON file and select M3U as the output. Auto-detect also converts CSV and JSON input to M3U.

Supported data fields

For CSV or JSON imports, use these field names (case-insensitive for CSV headers):

url (required), name, duration, tvg-id or tvgId, tvg-name or tvgName, tvg-logo or tvgLogo, and group-title or groupTitle.

JSON can be an array of channel objects or an object containing an entries array. CSV must include a url column. Empty rows and rows without a URL are skipped.

What is preserved during M3U conversion?

The converter maps common entry fields: display name, stream URL, duration, tvg-id, tvg-name, tvg-logo and group-title. Custom tags and other unsupported directives may not survive conversion to CSV or JSON. Keep your original file as a backup and review the output before using it.

For CSV imports, the header row must contain a url column. JSON input must be an array of channel objects or an object with an entries array. Rows without a URL are skipped.

Example: M3U to CSV and back

This playlist has a header with an EPG link, a group name that contains a comma and a channel name with quotation marks:

#EXTM3U x-tvg-url="https://guide.example/epg.xml"
#EXTINF:-1 tvg-id="a" tvg-logo="https://e.test/a.png" group-title="News, Sports",Channel A
#EXTVLCOPT:http-user-agent=Foo
https://example.com/a.m3u8
#EXTINF:120,"Quoted" Name
https://example.com/b.mp4

Converting it to CSV gives a header row and one row per entry. Values with commas or quotation marks are quoted, so the group stays in one cell:

name,url,duration,tvg-id,tvg-name,tvg-logo,group-title
Channel A,https://example.com/a.m3u8,-1,a,,https://e.test/a.png,"News, Sports"
"""Quoted"" Name",https://example.com/b.mp4,120,,,,

Converting that CSV back to M3U produces this playlist:

#EXTM3U
#EXTINF:-1 tvg-id="a" tvg-logo="https://e.test/a.png" group-title="News, Sports",Channel A
https://example.com/a.m3u8
#EXTINF:120,"Quoted" Name
https://example.com/b.mp4

All entries, names, groups and durations survive the round trip. Two things do not: the EPG link on the header and the #EXTVLCOPT line. The next section lists these and the other limits.

What is not carried over

  • Attributes on the #EXTM3U line. A header such as #EXTM3U x-tvg-url="..." becomes a plain #EXTM3U. If your player relies on that guide link, add it back to the first line of the new file.
  • Extra tag lines. Only the #EXTINF line of each entry is read. Lines such as #EXTVLCOPT or #EXTGRP are dropped.
  • Duplicates are kept. The converter does not remove repeated URLs. Use the merger or the editor for that.
  • Durations that are not numbers are written as -1 when converting to M3U. A value of -1 is the usual duration for a live stream.
  • Quotation marks inside attribute values (such as a logo or group name) are written as &quot; in the M3U, because the attribute syntax has no other way to hold them. Line breaks inside values become spaces.

When you open the CSV in a spreadsheet, a text value that starts with =, +, - or @ gets a leading apostrophe so it is not run as a formula. Plain numbers such as the duration -1 are left as they are. Keep your original file, and read the preview before you use the converted one.

Frequently asked questions

Can I convert M3U to CSV or JSON?

Yes. Select an M3U or M3U8 file and choose CSV or JSON as the output format. Common channel metadata is included as structured fields.

Can I convert CSV or JSON back to M3U?

Yes. Your input must contain a stream URL field named url. Optional channel fields can be included using the supported names listed above.

Does conversion test stream URLs?

No. The converter only reads and transforms playlist text and structured data. It does not contact stream URLs or test playback, availability, safety or content rights.

Are my files uploaded?

No. File reading, conversion and export happen locally in your browser.
