M3U File Format Explained: Structure, Tags and Examples

An M3U file is a plain-text playlist file that stores references to media locations. It can be a simple list of locations or an extended playlist with metadata describing each entry. M3U files are read by different media applications and workflows, so the exact tags and supported features can vary.

This guide explains the basic M3U playlist format, shows a small example, and describes common structural issues you can check locally.

What does an M3U file contain?

A basic M3U playlist can contain media locations as text lines. An extended M3U playlist commonly begins with the #EXTM3U header and uses #EXTINF records to describe the next item.

#EXTM3U
#EXTINF:-1,Example item
https://example.com/media/example.m3u8
  • #EXTM3U identifies an extended M3U playlist.
  • #EXTINF introduces metadata for the next media entry.
  • -1 is commonly used for a live or unknown-length item.
  • The text after the comma is commonly used as the display name.
  • The following line contains the media location.

Common M3U tags

Extended playlists can include comment-like directives beginning with #. An application may recognize only some of them, so support can vary between players and playlist formats.

  • #EXTM3U — marks the beginning of an extended M3U playlist.
  • #EXTINF — describes the media item that follows, including duration and display text.
  • #EXTVLCOPT — an application-specific option used by VLC in some playlists; it is not a universal M3U requirement.

Optional metadata attributes

Some playlist ecosystems place attributes on the #EXTINF line. For example, tvg-name or group-title may be used by particular applications. These are conventions rather than universal requirements of every M3U reader.

#EXTM3U
#EXTINF:-1 tvg-name="Example" group-title="Demo",Example item
https://example.com/media/example.m3u8

In this example, the attribute values and media URL are illustrative placeholders. A player may ignore attributes it does not support.

What is the difference between M3U and M3U8?

M3U8 is commonly used for UTF-8 encoded M3U playlist text. The extension alone does not prove that a file follows every rule of a streaming specification or that referenced media can be played.

Read our detailed M3U vs M3U8 comparison for more about encoding, extensions and common uses.

Common M3U file problems

  • Missing or misplaced #EXTM3U header.
  • An #EXTINF record that is not followed by a media location.
  • A media location without preceding metadata when an extended entry is expected.
  • An empty display name after the metadata separator.
  • Repeated media locations.
  • Invalid duration values in #EXTINF records.

How to check an M3U playlist file

You can inspect a local playlist with the online M3U playlist checker. Paste text or select a local .m3u or .m3u8 file. Processing happens in your browser tab; the playlist is not uploaded.

The checker reports supported structural issues, including missing URLs, basic #EXTINF problems and duplicate locations. You can export a JSON or CSV report. If you need to create a new file instead, use the browser-based M3U playlist generator to add entries and download a .m3u file.

For a complete walkthrough, read how to validate an M3U playlist. To build a file from scratch, follow our M3U playlist creation tutorial.

What an M3U validator cannot prove

A structural check does not establish that a media location is online, playback works, a playlist is secure, or content is licensed. M3U Playlist Inspector does not connect to media URLs or verify content rights. Only inspect playlists and media locations you own or are authorized to use.

Frequently asked questions

Is an M3U file a text file?

Yes. M3U playlists are text-based files that contain media locations and, in extended playlists, metadata lines.

Can I open an M3U file in a text editor?

Yes. A text editor can show the playlist's lines and tags. Avoid sharing files publicly if they contain private URLs, credentials or account details.

Can I create an M3U file with this website?

Yes. Open the M3U playlist generator, add entries with authorized media URLs, preview the text and download the generated file.

Can I use this guide to validate an M3U8 file?

The same basic playlist concepts are useful for M3U8 text files. The Inspector supports local M3U and M3U8 structure checks, but it is not a complete HLS validator.

Does a valid M3U structure mean the streams work?

No. Structure and playback are different. This tool does not connect to media URLs or test availability.
